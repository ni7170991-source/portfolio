Featured project

Sanad: replacing the paper debt notebook

In internal testing on Google Play Team lead, Flutter Android Arabic / RTL

A simple ledger for merchants who sell on credit, with statements that can be verified.

The problem. My father is a wholesale trader. Much of what he sells is on credit, and every night he added up what he was owed by hand. When a paper went missing, he lost money he had a right to. The apps he tried also did everything: inventory, sales, purchasing.

The product. Sanad stays small. A merchant records debts and payments per customer, sees every balance update automatically, and exports a PDF statement that carries a QR code anyone can scan to confirm the file was not edited.

My part. I led the mobile app and wrote the requirements and user stories. I worked with a Laravel backend developer and a UI/UX designer, and we shipped feature by feature across a six-sprint plan.

The pattern every feature follows

class CustomersCubit extends Cubit<CustomersState> {
  CustomersCubit(this._repository)
      : super(CustomersInitial());

  final CustomerRepository _repository;

  Future<void> loadCustomers() async {
    emit(CustomersLoading());
    try {
      emit(CustomersLoaded(await _repository.getCustomers()));
    } on ApiError catch (e) {
      emit(CustomersFailure(e));
    }
  }
}

Every API error, from login to validation, is parsed into one ApiError model, so screens can show server messages next to the right form field.

Email OTP sign-in

Code verification with masked email, token kept in secure storage, and an interceptor that attaches it to every request.

Debts and payments

Balances recalculate on every add, edit or delete. Credit limits are enforced and credit balances carry over. Quick-amount chips and a full-payment shortcut speed up entry, and a WhatsApp button reminds a customer who owes.

Reports with PDF export

Financial summary, daily inventory, customer balances, customer statement and general transactions. Exports run asynchronously and the app polls until the file is ready.

Verifiable statements

Each exported PDF is hashed, and a QR code on the page links to a check. Uploading the same file confirms it is unmodified.

Push and in-app alerts

Firebase Cloud Messaging for overdue debts, credit-limit warnings, report-ready notices and a daily reminder, plus a notification center inside the app.

Process

Requirements and user stories first, then the feature, then a stability check before the next sprint. A mock mode kept UI work moving while the API was being built.
